# ヒビログ (Hibilog)

食べログ × 野沢ヒビキ。Googleマップに保存したおすすめレストランを、社員・友人と共有するための Next.js アプリです。

デザインは [スペースマーケット](https://www.spacemarket.com/) のような検索＋カード一覧＋マップを意識しています。

## できること

- **利用シーンから探す**: 会食 / 個室 / カジュアル / とっておき / 記念日 / コスパ / 接待 / デート
- **値段帯**: カジュアル / ミドル / エグゼクティブ
- **ジャンル・エリア・Googleマップリスト** での絞り込み
- **地図表示**: 一覧は OSM マップ、店舗詳細では Google マップ埋め込み＋「Googleマップで開く」
- **AIマッチ Top10**: シーンや気分を入力するとマッチ度順に最大10件（`OPENAI_API_KEY` があれば OpenAI、なければローカルスコア）

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000

## 環境変数（任意）

`.env.local` に:

```
OPENAI_API_KEY=sk-...
```

## データについて

初期データは、ヒビキさんの Google マップ保存リスト（和食・鮨・肉・会食_middle・築地・コスパ・地方名・行ってみたい・LA・京都 など）の**分類構造を再現したシード**です。実店舗の全件エクスポート連携は、Google Takeout / Maps リストの CSV・GeoJSON を取り込む形で拡張できます。

## デプロイ

Vercel に接続してデプロイ可能です。

